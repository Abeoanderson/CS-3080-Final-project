# CS-3080-Final-project
Final project for CS 3080

Tetris game:

please run in a conda env or simaler using: 

  conda create -n tetris-env python=3.12 -y 
  
  conda activate tetris-env 
  
  pip install pygame 

  then from the directoy of main.py run python main.py to play
